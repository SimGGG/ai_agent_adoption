# 실험 공간 작업 규칙

- 기준값(기간, 직종 목록, 키워드 사전, 희소 숙련 기준, 난수 시드, 교차적합 겹 수 등)은 `config.yaml`에만 둔다. 모듈과 스크립트에 기준값을 직접 적지 않는다.
- 추정 결과를 보고 하이퍼파라미터(기계학습 모형의 학습 설정값)를 조정하지 않는다.
- 위약 검증(처치와 관계가 없어야 하는 숙련에서 효과가 나오지 않는지 확인하는 검증)에 쓰는 숙련 목록은 결과를 보기 전에 정한다.
- 교란변수(처치와 결과 모두에 영향을 주는 변수)는 같은 기간의 처치 변수로 만들지 않는다. 직전 기간의 값만 쓴다.
- 대용량 자료는 필요한 열만 읽는다. 공고 원문 열은 처치 판별에서만 읽는다.
- 시험과 가상 자료의 수치는 결과로 적지 않는다.
- 입력 파일이나 필요한 열이 없으면 무엇이 없는지 적은 예외를 내고 바로 멈춘다. 결합 전후로 행 수가 달라지면 멈춘다.
- 파이썬 명령은 저장소 최상위 폴더에서 `./tools/py.ps1`로 실행한다.
