# 실험 공간 작업 규칙

- 기준값(기간, 직종 목록, 키워드 사전, 희소 숙련 기준, 난수 시드, 교차적합 폴드 수 등)은 `config.yaml`에만 둔다. 모듈과 스크립트에 기준값을 직접 적지 않는다. 교차적합은 자료를 여러 묶음으로 나누어, 한 묶음의 예측값을 나머지 묶음으로 학습한 모형으로 구하는 방법이고, 폴드는 그렇게 나눈 묶음 하나이다.
- 추정 결과를 보고 하이퍼파라미터(기계학습 모형의 학습 설정값)를 조정하지 않는다.
- placebo 숙련(생성형 AI 활용과 관계가 없어야 하는 숙련으로, 같은 방법으로 추정했을 때 효과가 0으로 나오는지 확인하는 데 쓴다. `proposal.md` 7장 2번)의 목록은 결과를 보기 전에 정한다.
- 교란변수(처치와 결과 모두에 영향을 주는 변수)는 같은 기간의 처치 변수로 만들지 않는다. 산업별 AI 노출 정도는 외부 지수(Felten 등의 AIIE)를 쓴다.
- 대용량 자료는 필요한 열만 읽는다. 공고 원문 열은 처치 판별과 본문 글자 수 계산에서만 읽고, 글자 수만 저장한다.
- 시험과 가상 자료의 수치는 결과로 적지 않는다.
- 입력 파일이나 필요한 열이 없으면 무엇이 없는지 적은 예외를 내고 바로 멈춘다. 결합 전후로 행 수가 달라지면 멈춘다.
- 파이썬 명령은 저장소 최상위 폴더에서 `./tools/py.ps1`로 실행한다.
