# 확정 사항 기록

확정 사항은 이 문서에 먼저 적고 `experiments/config.yaml`에 반영한다. 설계 문서의 결정 표(2장)와 `proposal.md`가 다르면 설계 문서를 따른다. "미확정" 행은 자료 점검(S0) 보고서를 보고 정한다. 근거 열의 "기본값"은 확정 전에 `config.yaml`에 임시로 둔 값이다.

설계 문서는 `docs/superpowers/specs/2026-11-12-research-infra-design.md`이다.
